
Project Purpose:

SMARTOPS is a full stack software engineering project to manage and simulate a retail/workshop alLowing users to access:
- manage inventory
- dashboard for operations
- demand forecasting 
- AI Assistant

Built using React, Python, Langchain and host in Azure Platform with CI/CD pipeline

Target Users:
Warehouses
Retails
Small Convenience stores 

Core Problems being solved:

Business not having live management on the products or stock
Stock ordering decisions made manually without proper look at real data
Unable to predict demand and running with lack of stock or abundance of it
No proper suggestions based on live data

Version 1:

THe version1 focus is to build self sufficient Warehouse Management System(WMS) for Retail/Workshop without intelligence

Dashboard
Authentication
Inventory management and tracking 
Order management or simulation 
Product management 

Version 2:

Develop the working WMS with addition of intelligence 

Demand Forecasting 
Suggestions for order placing and inventory management based on current system data, inventory, orders, forecasts
AI recommendations based on current data allowing users to deploy smart decisions

Non-goals for now:
Advanced UI
Multi warehouse support
Different user roles
Supplier integration
Mobile app

Deployment Goal:
Deployed in Azure cloud services with CI|CD pipeline and docker 
A production and industry ready project for Resume
